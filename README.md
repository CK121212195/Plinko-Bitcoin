# 🟢 Plinko Bitcoin

物理演算でSatsが跳ねる、爽快なビットコイン・プリンクゲームです。

## 📝 概要
ピンの間をボールが不規則に落ちていく古典的なアーケードゲーム（Plinko）を、ビットコインテーマで美しく再現しました。重力と確率の軌道を見守り、高倍率のゾーンを目指します。

## 🚀 特徴
- 🌀 予測不能なバウンスを再現する正確な物理シミュレーション
- 🎨 ビットコイナー好みのスタイリッシュなダークカラーUI
- ⚡ サーバー不要で高速に動作する100%クライアントサイド設計
